# 功能概述

## 核心功能
- **地点搜索**：支持基于关键词、距离、类型的地点搜索
- **智能推荐**：根据用户位置和偏好推荐附近地点
- **地图可视化**：在地图上标注推荐地点
- **多轮对话**：支持多轮对话，理解用户上下文
- **评价查看**：查看地点的评价和评分

## 技术栈
- 前端：React, TypeScript, TailwindCSS
- 地图：高德地图 API
- 后端：Node.js, Express
- 数据库：MongoDB
- AI：OpenAI API

## 安装步骤
1. 克隆仓库
2. 安装依赖：`npm install`
3. 配置环境变量
4. 启动开发服务器：`npm run dev`

## 使用说明
1. 打开应用
2. 输入搜索关键词
3. 查看推荐结果
4. 在地图上查看标注
5. 与AI助手对话获取更多信息
